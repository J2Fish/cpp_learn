数组 一个存放了相同类型的数据元素的集合
    1、其中的的每个数据元素都是相通的数据类型
    2、由连续的内存空间组成

    定义法：
        数据类型 数组名[数组长度];
        数据类型 数组名[数组长度] = {值1,值2,...}
        数据类型 数组名[] = {值1, 值2, ...}
    数组有序，可通过下标访问数组中的元素,0开始数
    初始化时如果没有填写完全，则用0填充空白
    数组名
        可统计整个数组内存长度 sizeof(arr)  元素数：sizeof(arr) / sizeof(arr[0])
        就是数组在内存中的首地址 cout << arr << endl; -> 输出一个16进制数 转换为十进制最好用long long ，因为int 在64位会丢失精度
        数组名是常量，不可赋值

    二维数组
        定义法：
            数据类型 数组名[行数][列数];
            数据类型 数组名[行数][列数] = {{数据1,数据2},{数据3,数据4}};
            数据类型 数组名[行数][列数] = {数据1, 数据2, 数据3, 数据4};
            数据类型 数组名[ ][列数] = {数据1, 数据2, 数据3, 数据4};
            内行外列，先行后列
            行数可以省略，列数不行
        数组名 注释参考数组的数组名
            查看数组占用的内存大小 行数：sizeof(arr) / sizeof(arr[0]) 列数： sizeof(arr[0]) / sizeof(arr[0][0])

函数 将经常使用的代码封装，减少重复代码

    定义 
    回值类型 函数名(参数列表)
    {
        函数体
        return 返回值
    }
    函数不允许嵌套

    调用
    函数名(参数)

    值传递
    函数调用时，实参将值传入给形参，形参改变，不影响实参

    声明  当函数的定义在主函数的后面时无法被调用，在代码开头声明函数可调用函数
        格式：  回值类型 函数名(参数列表);
                int func(int a1, int a2);      

    函数的分文件编写
        1、创建后缀名为.h的头文件
        2、创建后缀名为.cpp的源文件
        3、在头文件中写函数的声明
        4、在源文件中写函数的定义
        5、在头文件中include源文件
        6、在主文件中include头文件
        自建库要打引号

    可以多次声明，但只能有一次定义
    函数的参数及返回值都可以没有 无返回值的回值类型写void ，不写调试会警告，但程序可以跑

    默认参数
        在参数后面赋值 
        有默认值的参数只能在所有无默认值的参数后面
        声明和实现中不能同时有默认参数 

    占位参数 ！用处后面补
        没名只有数据类型的参数
        可以给默认值

    函数重载 函数名相同，提高复用性 -> 可以在相同的函数名下，在输入不同的参数的情况下执行不同的操作 -> 针对不同的个体执行同样的操作，但描述时一致
        条件：
            1、统一作用域
            2、函数名相同
            3、函数参数的类型，个数，顺序不同
            ！引用/指针 作为重载条件时的注意事项：
                此时只读也算类型不同 但带const的形参函数只在传带const的实参时被调用
            ！重载时有默认参数的情况 -> 若 两函数在输入完 无/少 默认参数的函数的参数后都可以运行则出现 二义性 -> 可认为条件3中的“参数”实际为“无默认值的参数”
        ！函数的返回值不可作为函数重载的条件



指针 可通过指针间接访问内存
    内存一般以十六进制表示
    可利用指针变量保存地址
    &变量名 表示取地址
    1、定义
    数据类型 * 指针名;
    2、赋值
    指针名 = &变量名;
    数据类型 指针名 = &变量名;

    3、使用
        1、直接得到所指内存 p
        2、解引用 访问内存中的数据 *p
        3、解引用 修改内存中的数据 *p = ...
    4、指针所占的内存空间
        在32位系统下，占用4个字节
        在64为系统下，占用8个字节
    
    空指针 指针变量指向内存中编号为0的空间
        一般用于初始化指针变量
        空指针指向的内存无法访问 0~255的内存编号为系统占用,不可访问 -> 即不可解引用 
            打印空指针是合法的,但解引用空指针不合法
            解引用空指针 编辑器检查不出语法错误,但不能跑,程序会崩溃
            
    野指针 指针变量指向非法的内存空间
        打印野指针是合法的,但解引用空指针不合法
        解引用野指针 编辑器检查不出语法错误,但不能跑,程序会崩溃

    空/野辨析
        空指针可以检查其是否可用、是否是一个正常指针,而野指针无法检查
        即空指针是可控的,而野指针并不可控
    const 修饰指针
        1、const修饰指针 -> 常量指针
        const int* p = &a;
        const 修饰到*，则*p不能改 *p即指向的值
        2、const修饰常量 -> 指针常量
        int* const p = &a;
        const 修饰到p，则p不能改 p即指向
        3、const即修饰指针，又修饰常量
        const int* const p = &a;
        const 即修饰到* ，又修饰到p， 则两者都不能改
    
    书+： int* 为复合类型，指 “指向int 的指针”，而*前面的数据类型即为指针指向的数据类型
    指针的运算以其指向的数据类型大小为单位
    
    指针与数组
        数组名就是其首地址
        仅用数组名定义时指针指向其首项的地址，后续移动中也只会指向其某项的地址
        对数组名取地址，将获取整个数组的地址 （数值上等于首地址，但在指针的后续操作中会按数组为单位进行）
        arr[3] = *(arr + 3) -> 对 「数组指针」 索引 等同于 「解引用」 索引处的地址
        sizeof 指向数组的指针 会得到指针的长度
    
    指针与函数
        1、值传递 无法改变实参
        int a = 0;
        int b = 1;
        swap01(a, b);
        cout << "a:" << a 
             << "\t"
             << "b:" << b 
             <<endl; //未交换
    
        2、地址传递 可通过指针改变实参的值
        swap02(&a, &b);
        cout << "a:" << a 
             << "\t"
             << "b:" << b 
             <<endl; //已交换
        
        const 
            值传递会占用过多内存，此时使用地址传递，
            为防止误操作导致在内部修改，可在形参定义处+const

面向对象

内存四区 代码区，全局区，栈区，堆区     
    在不同区域存放的数据，赋予不同的生命周期，可提高编程的灵活度
    编译生成exe后，未执行程序前被分为两个区域 - 代码区与全局区
        代码区： 存放函数体的二进制代码，由操作系统管理
            共享 - 对于频繁调用的程序，只需有一份代码 
            只读 - 防止程序以外修改了指令
        
        全局区：存放全局变量和静态变量以及常量，在程序结束后由操作系统释放
            全局变量->主函数外声明的变量
            静态变量->static 修饰声明的变量
            常量 -> 分为字符串常量和全局常量，    局部常量（局部常量不在全局区存储）
            代码示例
                main函数外
                    int g_a = 10; 
                    const int c_g_a = 10;
                main函数内
                    //全局区
                    //全局变量->主函数外，静态变量，常量
                    //普通的局部变量
                    int a = 10;
                    int b = 10;
                    cout << "局部变量" << endl;
                    cout << "&a = " << (long long)&a << endl;
                    cout << "&b = " << (long long)&b << endl;
                    cout << "全局变量" << endl;
                    cout << "&g_a = " << (long long)&g_a << endl; 
                    //静态变量
                    static int s_a = 10;
                    cout << "静态变量" << endl;
                    cout << "&s_a = "  << (long long)&s_a<< endl; 
                    //常量 - 分为字符串常量和全局常量，局部常量 
                    cout << "字符串常量" << endl;
                    cout << "&'sdafsadf' = "  << (long long)&"sdafsadf" << endl;
                    //全局常量-const修饰的全局变量，局部常量则是const修饰的局部变量
                    const int c_a = 10;
                    cout << "局部常量" << endl;
                    cout << "&c_a = " << (long long)&c_a << endl;
                    cout << "全局常量" << endl;
                    cout << "&c_g_a = " << (long long)&c_g_a << endl;
                    cout << "由此可知，全局变量，静态变量，常量(不含局部常量)在内存中位于同一区域（全局区） const仅表示“只读”，与内存区无关" << endl;
                
                输出：
                局部变量
                &a = 6291068
                &b = 6291064
                全局变量
                &g_a = 140700647829504
                静态变量
                &s_a = 140700647829508
                字符串常量
                &'sdafsadf' = 140700647833702
                局部常量
                &c_a = 6291060
                全局常量
                &c_g_a = 140700647833600
                由此可知，全局变量，静态变量，常量在内存中位于同一区域

            
    
    栈区：由编译器自动分配释放，存放函数参数值，局部变量，局部常量等
        ！不要返回栈区数据的地址，系统会直接释放
        返回的第一次调用会有暂时的保留，后面就没了

    堆区：由程序员分配和释放，若程序员不释放，组程序结束时由操作系统回收 实则存储形式类似于链表
        在C++中主要用new在堆区开辟内存，用delete释放内存
            指针本质为局部变量存在栈区（地址名存在栈区），但指针保存的数据在堆区（地址和上面的数据在堆区）
            代码示例：
                main内
                    //在堆区开辟内存
                    int* p = func();
                    cout << *p << endl;
                    cout << *p << endl;
                    cout << *p << endl;
                    delete p;
                    cout << *p << endl;
                main外
                    int* func(){
                        int* p = new int(10); //new 修饰返回对应指针
                        return p;
                    }
                输出：
                    10
                    10
                    10
                    8027664
        在释放数组时，要加中括号：
            delete[] arr;


引用 两个指向同一地址的变量名 
    语法
        数据类型 &别名 = 原名;  别名和原名可以一样
    代码示例：
        int a = 10;
        int &b = a;
        cout << a << endl;
        cout << b << endl;
        b = 30;
        cout << a << endl;
        cout << b << endl;
        cout << &a << endl;
        cout << &b << endl;
        输出：
        10
        10
        30
        30
        0x5ffe74
        0x5ffe74
    ! 1、引用必须初始化 -> 即不能不定原名 / 必须引用一块合法的内存空间
    ! 2、引用初始化后不可更改 在后面用 b=a 是赋值
    
    作函数参数 可改变在函数内实参，比指针简化一点
        代码示例：
            void swap(int &a, int &b){
            int temp = a;
            a = b;
            b = temp;
            }

            int a = 10;
            int b = 20;
            swap (a, b);
            cout << a << "\t" << b << endl;
            输出：
            20      10

    作函数返回值
        ！不要返回局部变量的引用 第二次调用会被清掉
        函数返回地址/引用时,函数的调用课作为左值进行赋值
    引用的本质是 一个指针常量 -> 指向固定地址的指针

    常量引用 用于修饰形参，防止误操作 即将值设定为只读 
        const int&  ref = 10 => int temp = 10; const int& ref = temp;
    
    &与*
        声明时, & 声明别名（与本名是同一块内存，只在人类眼中不一样）
                * 声明指针（保存地址的变量）
        使用时, &表示引用（取地址）
                *表示解引用（按地址取值）

    属性设置为私有利于

    struct 与 class 的区别
        都可以用于写类，唯一区别在于默认的访问权限不同
        struct 默认为公共权限
        class 默认为私有权限
        一般习惯上认为struct 不写复杂逻辑


    对象特性
        对象的初始化和清理  构造函数，析构函数 
            C++ 会自动调用构造函数和析构函数，若我们不提供构造与析构，编译器会提供空实现的构造和析构
            构造函数
                语法 类名(){}
                    1、没有返回值，不写返回值类型
                    2、函数名与类名相同
                    3、可以有参数，所以也可以重载
                    4、调用对象时会自动调用构造函数，且只会调用一次

                分类
                    按参数分：有参构造和无参构造（默认构造）
                    按类型分：普通构造和拷贝构造
                    
                    拷贝构造 
                        Person(const Person &p) 参数的类型是本类，只读，引用
                        会调用的时机：
                            1、使用一个创建完毕的对象来初始化一个新对象
                            2、用值传递给函数参数传值       函数值传递方式以对象作参数时，函数实际上会拷贝出一个函数在函数内部使用
                            3、以值方式返回局部对象         局部对象作函数返回值时也会拷贝后传出

                        浅拷贝  简单赋值拷贝
                               如果在堆区开内存保存数据，，要在析构时释放 浅拷贝会把同一地址拷贝过去，可能出现重复释放的问题
                        用深拷贝解决 在堆区申请空间进行拷贝操作=> 再开一个新的内存存拷贝数据

                        若属性有在堆区开辟的，要自己提供拷贝构造函数，防止浅拷贝的问题


                调用方式：
                    括号法
                        !无参构造函数不加括号，会被认为是函数声明
                    显示法
                        类似python Person p = Person();
                        匿名对象：不带变量名 ，在当前行执行结束后，系统会立即回收掉匿名对象
                            Person(10);
                            !不要用拷贝构造函数初始化匿名对象 会被识别成对象声明
                    隐式转换法
                        Person p4 = 10 => Person p4 = Person(10)
                
                调用规则：
                    1、默认情况下编译器会给空的默认构造，析构函数，会给一个对属性进行值拷贝的默认拷贝函数
                    2、若有用户定义的有参构造函数，则无无参默认，但会给默认拷贝函数
                    3、若定义了拷贝构造函数，则c++不会再提供其他构造函数
                初始化列表
                    语法：构造函数(): 属性1(值1),属性2(值2)...{}
                        不用在构造函数内再赋值，可以直接赋值给属性
                        会直接赋予类定义中的值
                    灵活初始化：构造函数(a, b, c): 属性1(a),属性2(b)...{}
                        可在对象中各自赋值


            析构函数 
                语法~类名(){}
                    1、无返回值，不写返回值类型
                    2、函数名与类名相同，在名称前加~
                    3、不可以有参数，因此不可以重载
                    4、程序在对象销毁前会自动调用够细，且只会调用一次
                    !有system("pause")时，main中释放的对象析构函数会在关闭的瞬间运行
    类对象作为类成员
        一个类的成员可以是另一个类的对象，称为对象成员
        代码示例：
            class A{}
            class B{
                A a;
            }
        构造与析构的顺序
            构造：先内后外
            析构：先外后内

    静态成员 - 同一文件环境下整个类的所有对象的共同之处 有访问权限
        在成员变量和成员函数前加static
        分为：
            静态成员变量
                所有对象共享同一份数据
                编译阶段分配内存
                类内声明，类外初始化
                可通过 类名，对象名 访问 对象名访问需要用作用域解析运算符 :: 来访问
            静态成员函数
                所有对象共享同一个函数
                静态成员函数只能访问静态成员变量
                同样有两种访问方式，类外声明，类内定义
                静态成员函数可以访问静态成员变量
        代码示例：
            class  Person 
            {
            public:
                //静态变量 类内声明
                static int m_a;
                string name;
                static void func()
                {
                    cout << "类静态函数调用" << endl;
                }
                void showpersonname(int name)
                {
                    this -> name = name;
                }

            }

            int  main{
                Person* p = NULL;
                p -> 
                //类外初始化
                int Person::m_a = 100;
                Person a;
                cout << a.m_a << endl;
                //以类调用
                cout << Person :: m_a << endl;  
                return 0; 
            }

    成员变量和成员函数分开存储
        只有非静态成员变量才属于 类的对象
        空对象会分配一个字节空间，为了区分空对象占内存的位置
        非空对象不会加上一开始的一个字节
    
    this 指针概念 也是一个指针常量 指向本对象 const Person* const this
        调用函数的对象区分：this 指针 无需定义，隐含于非静态成员函数内，可直接调用
        用途：
            形参与成员变量重名时，可用this指针来区分 this代表对象本身
            类的非静态函数中返回对象本身，可使用 *this 可用作链式编程
        空指针访问成员函数，需要注意有没有使用this指针
            空指针调用的函数中有this，则this无法找到指向的对象，导致报错
            可在使用了this的函数中对空指针加条件返回
    
    const 修饰成员函数
        常函数语法：在函数名后面加const 使this指针指向的值也不可修改
            因此常函数不能修改 成员属性 
        常对象：在声明对象前加const
            成员属性声明时加关键字mutable可以在常函数和常对象中修改
            常对象只能调用常函数，也不能修改属性
    类外实现函数：
        类名前加定义域解析符后正常写
    友元
        可在类外访问类内私有成员的特殊函数或类
        关键字：friend
        实现： 在类内添加带friend的声明
            1、全局函数做友元 void friend bbb(int arg1);
            2、类做友元 class friend aaa;
            3、成员函数做友元 要带定义域解析符 friend void aaa::bbb(arg1);

    继承    有父级的共性，有自己的特性
        语法  class 子类 : 继承方式 父类
            class language{
                public :
                    language(){
                        cout << "a language" << endl;
                    }
            };
            class Java: public language{
                    public: void content(){
                        cout << "Java" << endl;
                    }
            };
        方式    按权限分类，分为公共继承，保护继承和私有继承
            父类的私有属性无法继承
            低于继承权限的父类属性会纳入子类的继承权限，其余权限的父类属性则会按原权限纳入子类权限
            如以保护权限继承的子类，父类中公共，保护权限的属性共同纳入子类的保护权限，而父类私有权限的属性不继承
        继承的对象模型
            父类的所有非静态成员都会被子类继承
            但父类的私有成员无法访问
            cmd可查看对象模型 跳至路径后 输入命令 cl /dl reportSingClassLayout 类名 文件名
        构造与析构的顺序
               子类创造对象的同时，父类也会创造一个对象
               父类构造 -> 子类构造 父类析构 -> 子类析构
        父子类重名成员的处理
            子类的成员可以直接访问
            父类要加作用域 s.base::m_A;
            同名函数不会重写，父子的函数都可以访问
            父类的同名重载和子类的同名函数没关系，还是要作用域
            静态和非静态都是，但静态可以用类名访问 
        多继承
            语法： class 子类: 继承方式:父类1 , 继承方式:父类2, 继承方式:父类3
            多继承中可能出现同名成员，要用作用域区分
        菱形继承
            两个派生类继承同一个基类，某个类又同时继承两个派生类，则是菱形继承
            问题：
                1、最高父类的东西会出现二义性
                2、最高父类的东西会重复
            解决：
                利用虚继承 
                    语法： class 子类名 :virtual 权限 父类名{};
                    父类变成虚基类
                    共有的数据变为同一个
                    不同的派生类继承统一指针，指针指向一个基类
        父类的指针、引用可以指向子类
    多态
        静态多态：函数重载运算符重载
        动态多态：派生类与虚函数实现运行的多态
        区别：
            静态的函数地址在编译阶段确定
            动态的函数地址在运行阶段绑定 基类成员函数定义前加virtual
        动态多态要出现继承关系，子类对父类的虚函数重写  重写：返回名，函数名，参数列表，
        父类的指针或引用指向子类的对象时使用
        底层：
            When the fatherclass has a virtual func, each instance of that class will have a vfptr which points to the vtable(which stores the addresses of all its virtual functions)
            When the instance of son class is created , the vfptr will point to the son's virtual function table in which the father's vfunc is saved.
            If we override the virtual func in the son ,the vtable will replace the father's vfunc with the son's.
            Then we achieve the polymorphism
            emphasis: instances have vfptr, classes have vtable
        code: 
            class Animal01{
                public：
                    //使用虚函数
                    virtual void speak(){
                        cout << "animal01 is talking !" << endl;
                    }
            };
            
            class Animal02{
                public：
                    //未使用虚函数
                    void speak(){
                        cout << "animal02 is talking !" << endl;
                    }
            };

            class Cat:Animal01{
                public :
                    void speak(){
                        cout << "cat is talking ! " << endl;
                    }
            }

            class Dog:Animal02{
                public :
                    void speak(){
                        cout << "dog is talking ! " << endl;
                    }
            }

            void test01(Animal01& animal){
                animal.speak();
            }

            void test02(Animal02& animal){
                animal.speak();
            }

            int main(){
                Cat cat;
                test01(cat);
                //>>> cat is talking
                Dog dog;
                test02(dog);
                //>>> animal02 is talking

                return 0;

            }
